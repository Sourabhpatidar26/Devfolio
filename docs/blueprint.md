# **App Name**: Source Portfolio

## Core Features:

- Interactive Hero Section: Interactive hero section with Sourabh Patidar's professional headshot and a brief, engaging introduction. The section adapts to different screen sizes and includes subtle parallax scrolling.
- Dynamic Project Display: Dynamic project display showcasing Apple Fix Pros, Vinyasa, Groov Consumer App, Wealthcon App, and NPS Overview App with animated transitions. Each project includes a brief description, tech stack, and a link to a live demo or GitHub repository. Each project thumbnail is generated automatically.
- Interactive Skill Visualization: Interactive skill bars or charts visualizing proficiency in HTML5, CSS3, JavaScript, React.js, Next.js, React Native, Swift, Node.js, Express.js, MySQL, MongoDB, Git, Xcode, VSCode, Postman, Bootstrap, and Tailwind CSS. Each skill can be clicked to reveal more details about Sourabh's experience with the technology.
- Contact Form: Contact form with animated input fields and a clear call to action for recruiters and clients to get in touch. Include direct links to Sourabh's email (sourabhpatidar389@gmail.com) and LinkedIn profile (linkedin.com/in/sourabh-patidar).
- Resume Download: A downloadable PDF version of Sourabh's resume for offline viewing and printing.
- Personalized Welcome: Use a generative AI tool to generate a short custom message depending on the role of the user visiting the portfolio page (e.g. potential client or recruiter).

## Style Guidelines:

- Primary color: Deep blue (#3F51B5), reflecting Sourabh's professionalism, confidence, and forward-thinking approach. This color establishes trust and reliability, essential for attracting recruiters and clients.
- Background color: Light gray (#F0F2F5), provides a clean, modern backdrop that ensures readability and highlights the content without distraction. Its subtle, desaturated tone complements the primary color.
- Accent color: Vibrant orange (#FF9800) for call-to-action buttons and interactive elements. This energetic color draws attention to key areas, encouraging engagement and providing a clear visual contrast.
- Clean and modern font for headings and body text, ensuring readability and a professional look.
- Use a set of consistent and modern icons for skills and technologies.
- Responsive design with a clean, grid-based layout that adapts seamlessly to different screen sizes and devices.
- Subtle transitions and animations on project cards, skill bars, and form elements to enhance user experience.
